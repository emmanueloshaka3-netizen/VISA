What is stored today

Only your display preferences (theme, personality choices, voice sliders) in this browser. No conversations are stored anywhere yet.

What will change

From Stage 3, conversations and memories are saved on the server so they survive restarts. Each person's data stays separate, and you will be able to delete any item or everything.

API keys
